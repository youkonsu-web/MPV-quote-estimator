# Muplbi Quote Estimator

뮤플비 영상 제작 모의견적 프로토타입입니다.

## 열어보기

`index.html`을 브라우저에서 열면 바로 실행됩니다.

## 포함 기능

- 영상 유형 선택
- 촬영만 유형 선택
- 촬영 필요일수 조정
- 촬영 0일 설정 시 편집 중심 견적 산출
- 지방촬영 선택 시 유류비 반영
- 영상길이 조정
- 기획안, 콘티/스토리보드, 성우/내레이션, 외국인 성우, 드론, 사진, 모델 섭외, 외국인 모델, 헤어/메이크업, 장소 대여, 동시녹음, 2D 그래픽/자막 옵션 반영
- 기본 편집 분당 30만원 반영
- 영상 유형별 종합편집/마스터링 분당 단가 반영
- 모션그래픽 유형 선택 시 종합편집/마스터링 분당 100만원 반영
- 컬러 그레이딩, BGM/SFX, 자막 통번역 필요 옵션 반영
- VAT 별도/포함 실시간 계산
- 스크롤을 따라오는 실시간 예상 견적 패널
- 견적 문의 페이지로 바로 제출되는 상세 견적 문의 폼
