# Muplbi Quote Estimator

뮤플비 영상 제작 모의견적 프로토타입입니다.

## 열어보기

`index.html`을 브라우저에서 열면 바로 실행됩니다.

## 포함 기능

- 영상 유형 선택
- 촬영 필요일수 조정
- 완성 영상 길이 조정
- 납품본 개수 조정
- 제작 난이도 선택
- 기획, 성우, 드론, 사진, 모델, 장소, 2D 그래픽 옵션 반영
- VAT 별도/포함 실시간 계산
- Pre / Production / Post 단계별 금액 분해
- 과거 견적 기반 적정 범위 안내
